# ChatGPT — интеграция и ограничения

- Проверить доступный способ подключения к локальному MCP в текущем плане ChatGPT.
- Не путать встроенный Remote Desktop Commander с собственным MCP endpoint проекта.
- Уточнить ограничения на remote MCP, OAuth и публичный HTTPS endpoint.
- Для ChatGPT Web исследовать browser bridge отдельно от MCP.
- Не использовать платный API как обязательный маршрут.
- Не сохранять cookies, токены и сессии в репозитории.
- Зафиксировать воспроизводимый вариант подключения или чётко описать ограничение.
