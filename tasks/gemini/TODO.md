# Gemini — интеграция

- Разделить Gemini API и Gemini Web как два независимых канала.
- API не является обязательным, если требует платную тарификацию.
- Для Gemini Web исследовать управление через существующий браузер/CDP/Ui.Vision.
- Проверить реальные возможности tool calling и файловых операций для бесплатного web-интерфейса.
- Не считать Web UI нативным MCP клиентом.
- Не хранить сессионные данные и cookies в Git.
- Зафиксировать версию, capability profile, ограничения и способ проверки.
