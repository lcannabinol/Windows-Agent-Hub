# Qwen Code — проверка MCP

- Установить фактическую поддержку MCP у текущей версии CLI/Desktop.
- Зафиксировать точный формат конфигурации.
- Проверить stdio, tools/list и tools/call на тестовом MCP server.
- Зафиксировать ограничения на число серверов, tool descriptions и timeout.
- Не считать Desktop Commander встроенным или доступным автоматически.
- Не создавать отдельный venv без необходимости.
- Не менять пользовательскую конфигурацию.
- Результат: docs/providers/QWEN.md и воспроизводимые шаги проверки.
