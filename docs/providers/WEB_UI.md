# Web UI provider strategy

Web UI — отдельный канал доступа к AI-сервису, не API provider в обычном смысле.

Кандидаты:
- ChatGPT Web
- Gemini Web
- Qwen Web

Подход:
1. Сначала проверить, можно ли использовать MCP/tool calling нативно в выбранном клиенте.
2. Если нельзя — исследовать browser bridge через существующий браузер, CDP или Ui.Vision.
3. Не автоматизировать логин, CAPTCHA и обход защит.
4. Не считать DOM/UI стабильным API.
5. Сессии и cookies остаются в профиле браузера пользователя.
6. Возвращаемый текст/файл/статус передавать как есть; HUB не анализирует содержимое ответа.
7. Учитывать лимиты бесплатного web-тарифа; не подменять их платным API.

Для каждого сервиса отдельный capability profile: поддержка файлов, изображений, контекста, tool calling, загрузок, потокового вывода, браузерных ограничений.
