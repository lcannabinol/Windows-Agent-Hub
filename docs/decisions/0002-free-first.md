# ADR-0002: Free-first и отсутствие обязательных платных API

Статус: принято как пользовательский приоритет. Дата: 2026-11-10.

## Решение
Проект должен быть работоспособен без платных API и без обязательной локальной LLM.

Приоритет:
1. Уже установленные инструменты и доступы пользователя.
2. Бесплатные web UI сервисов с браузерным взаимодействием.
3. Бесплатные/open-source локальные компоненты, если они укладываются в ресурсы.
4. Бесплатные API tiers — только как опциональный канал с учётом лимитов и условий.
5. Платные API не входят в обязательную архитектуру.

## Ограничения железа
HOME-PC: Intel i7-6700, 16 GB RAM, AMD RX 580 4 GB. Локальные модели не являются основой проекта.

## Последствия
HUB остаётся лёгким транспортным слоем. Он не выбирает провайдера и не решает, какой тариф использовать. Клиент/пользователь выбирает доступный канал. Browser UI adapters должны учитывать нестабильность интерфейсов и не имитировать API.
