# План Windows-Agent-Hub

Дата: 2026-11-10. Стадия: пересборка концепции и стартовая спецификация.

## 1. Назначение
Локальный Windows HUB — транспортный и интеграционный слой между внешними AI-клиентами и существующими MCP-серверами/инструментами.

Внешний AI-клиент сам понимает запрос, выбирает модель, планирует, выбирает инструменты, анализирует ответы и решает, что делать дальше.

HUB только публикует инструменты, маршрутизирует вызовы, возвращает исходные ответы и показывает техническое состояние соединений.

## 2. Не входит в проект
- Planner, Supervisor, AI Router, Verifier, Intent Engine.
- Собственная обязательная LLM.
- Агентный цикл и самостоятельное принятие решений.
- Замена Desktop Commander или Ui.Vision.
- Платный API как обязательное условие.
- Отдельные Python venv для каждого провайдера без конфликта зависимостей.

## 4. MVP
Внешний AI-клиент подключается к HUB, видит разрешённые инструменты, вызывает один инструмент; HUB пересылает вызов upstream MCP и возвращает ответ без самостоятельной интерпретации.

## 5. Правило
Сначала один рабочий вертикальный путь через уже установленный Desktop Commander. Не создавать десяток адаптеров до проверки первого реального MCP proxy.
