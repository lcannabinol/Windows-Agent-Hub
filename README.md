# Windows-Agent-Hub

Локальный лёгкий MCP bridge для Windows: соединяет внешние AI-клиенты с уже существующими MCP-серверами и инструментами.

**HUB не является AI-агентом.** Он не планирует задачи, не выбирает модели, не анализирует ошибки, не проверяет результат и не перепланирует работу. Интеллект и агентный цикл остаются у внешнего AI-клиента.

## Что делает HUB
- Принимает MCP-подключения.
- Публикует доступные инструменты из реестра upstream-серверов.
- Фильтрует доступные группы инструментов по профилю клиента.
- Перенаправляет tool calls к upstream MCP/адаптерам.
- Возвращает upstream-результаты, ошибки и транспортные статусы.

## Приоритеты
- Бесплатные и уже установленные решения.
- Никаких обязательных платных API.
- Не требовать локальную LLM или GPU.
- Не дублировать Desktop Commander, Ui.Vision, AutoHotkey.
- Не создавать отдельный venv для каждого AI-провайдера без технической причины.
- Новые файлы, SDK, окружения и кэши размещать на D:, не расходовать C:.
- Секреты, cookies и токены не хранить в Git.
